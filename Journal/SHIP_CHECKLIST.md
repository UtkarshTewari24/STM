# Pre-shipping checklist

Do this before submitting.

## Files

- [x] `BOM.csv` has prices and purchase links.
- [x] Gerbers are in `PCB/`.
- [x] PC software is in `Software/`.
- [x] Fusion 360 source is in `CAD/`.
- [x] Controller source is in `Firmware/`.
- [ ] Add a `.STEP` export of the full assembly.
- [ ] Port and test the firmware for the ESP32 in the BOM.

## README and evidence

- [ ] Add photos after the build starts.
- [x] Add the CAD screenshot and circuit pictures.
- [ ] Put a BOM table in the root README.
- [ ] Get feedback and note what changed.

## Final check

- [ ] Check the links and file paths on GitHub.
- [ ] Check that `git status` is clean.
- [ ] Read the current Stardance shipping guide again.

This does not guarantee approval. It is just a last check.
